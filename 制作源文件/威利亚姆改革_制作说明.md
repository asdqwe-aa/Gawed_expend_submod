## 开局与灾难

开局首个月度灾难检查时，A13 自动进入 `gcd_welyam_reform`，显示 `gcd_welyam.1`。事件选项将当时全部本国省份的自治度**设为 30**，不是增加 30。开局正文取自用户第一张截图；未提供的其他事件正文统一使用“事件正文待补”。

灾难修正为全国叛乱度 +2、贵族忠诚均衡点 −50%、政府改革点数增长 +20%。三个特殊机制的介绍写在灾难说明中：

1. 贵族忠诚低于 20 连续满 365 天，触发内战事件。每日检查；恢复到正好 20 也会重置计时。任务三第一分支可以永久阻止尚未发生的内战。
2. 两年一次的固定 **12k** 贵族叛军：用户要求必须固定数量，暂留计时接口，**尚未生成实际叛军**，没有用 `size = 12` 或缩放叛军冒充。借款使用 Anbennar 已有的富商贷款禁用标记。完成任务二后立刻解除本灾难施加的借款禁令，并停止后续叛军接口；灾难结束也会清理。
3. 灾难期间，A13 主动对 A01（洛伦特）或当时的皇帝宣战，若 A24 是其属国且独立倾向严格大于 50，A24 独立并加入被宣战方。阿德肖叛乱尚未设计，按用户确认只预留 `gcd_welyam_on_adshaw_revolt_effect`，不误接到冰冻喉的克洛维叛乱。将来由 A13 保存敌方为 `gcd_welyam_external_enemy` 后调用。

三个特殊机制均有灾难有效期检查；结束后不再启动。已经独立的国家、已经生成的叛军或已经开始的内战不因结束灾难而倒退。正常完成末项任务要求处于和平。

`gcd_welyam.100` 的选项先释放指定叛乱国的本国非首都核心，再执行 `release_all_possible_countries`，并让现有属国独立。大边区使用专用 CB `cb_gcd_gawedi_civil_war` 对 A13 宣战，战争目标为夺取首都，指定省份为加韦顿 221。其余五个点名国家加入大边区一方，威斯特摩尔不检查独立倾向。

外交 `requestpeace` 限制双方手动、单独议和；`enforce_peace` 限制第三国强制和平。空和平条款列表和很低的 AI 和平倾向仅作为补充，不能单靠它们声称禁止白和平。

只有两条胜负事件路径，先锁定结局，再由选项结算：

- 大边区战争攻击方成员控制加韦顿 → `gcd_welyam.101` → 大边区吞并 A13，并附庸 B83、B84、A52、A51。**不附庸 A24**。A13 玩家失去国家，不自动转交大边区。
- A13 对 A50 的战争分数达到 99 → `gcd_welyam.102` → A13 吞并 A50、B83、B84、A52、A51、A24。改革灾难仍须通过末项任务结束。

首都被普通叛军或无关第三国占领不会判为大边区胜利。每日检查及首都围城结束回调均核对专用 CB、A50/A13 两个战争领袖，避免无关战争误触发结算。

### 待用户实机确认的引擎行为

静态检查不能证明外交限制是否覆盖游戏内所有和平入口、国家释放后的自动军队与外交状态、AI 参战及吞并结算。正常开局 A50 原本不存在，释放后只有本场内战；EU4 的 `join_all_offensive_wars_of` 会加入领头国**所有**进攻战争，若在特殊旧存档中 A50 已独立且另有进攻战争，需要另行处理该边界。相同限制也适用于威斯特摩尔加入被宣战方的防御战争。

本轮没有添加未指定的叛乱国兵力奖励，也未启动或操控游戏。建议用户安排新加韦德测试局验证首月事件与分支；旧存档任务完成状态和配偶标记会影响新内容。

## 兼容与重建

新增独立脚本不覆盖魔法、奇械或决议 GUI。为了保留原有外交限制和卡丽娜创建事件，以下两份运行文件以当前本机 Anbennar 文件为基础生成，原内容逐字节保留，只有 `GCD_REFORM_BEGIN/END` 注释之间是新增片段：

- `common/diplomatic_actions/00_diplomatic_actions.txt`
- `events/Flavour_Gawed_A13.txt`

Anbennar 更新后，运行：

```powershell
python tools/build_reform_compat.py "你的 Anbennar 模组目录"
python "制作源文件/EU4本地化转码.py" "制作源文件/威利亚姆改革_中文原文.yml" "localisation/gcd_welyam_reform_l_english.yml"
python tools/validate_reform.py "你的 Anbennar 模组目录" "你的 EU4 游戏目录"
python tools/check_encoding.py
```

生成器通过语法位置插入，保留其余上游内容；找不到预期事件或外交块时会失败，不会猜测插入位置。`制作源文件/改革兼容基线.json` 记录本次上游及生成文件的 SHA-256，不记录用户私人路径。
